Raycasting & Unity Physics

Today I worked on my Unity project and learned about raycasting. It's amazing how physics engines handle light and collisions. I always thought it was just about visual rendering, but it's deeply tied to gameplay logic as well.

First, I experimented with shooting a ray from the camera to the mouse position. It’s the fundamental concept behind almost every clicking interaction in 3D games.

Fig 1. Testing 2D raycasting from the player to the mouse cursor.

The Code Behind It

Writing the actual C# script was easier than I thought. Unity provides a really clean API for physics. Here is the core snippet I wrote today:

PlayerInteraction.cs
// Cast a ray from the camera to the mouse position
Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);
RaycastHit hit;

if (Physics.Raycast(ray, out hit, 100f)) {
    Debug.Log("We hit: " + hit.collider.gameObject.name);
    
    // Destroy the object we clicked on
    if (hit.collider.CompareTag("Enemy")) {
        Destroy(hit.collider.gameObject);
    }
}
