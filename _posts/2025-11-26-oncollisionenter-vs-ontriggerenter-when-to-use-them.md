First when we use OnCollisionEnter and why it needed? So basically we use OnCollisionEnter when objects should physically bump into each other.

Like when car crashes into wall, ball bouncing in plane and etc.

Second when we use OnTriggerEnter and why?

We use OnTriggerEnter when we need to know that objects are contacted with each other but not physically like when we shoot enemy, collect coins and etc.
