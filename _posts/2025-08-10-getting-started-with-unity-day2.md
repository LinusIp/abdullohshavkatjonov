Today I’m going through creating project in Unity. First of all we must to open Unity and go to Projects,

After that you can see the projects what you have, if you don’t you can create a new one by pressing on “New Project” button.

Once you pressed you can see a multiple types of projects what you can choose one.

After choosing on, you must to set a name of project and the path to the folder where you will store your Unity projects in our case its a Unity folder created by me in my main folder, so like this we will press a create project button and after few seconds a new window will open, which is the our project.

And this is how it will looks like, our workspace, in the center a 3 dimensional space which calls a Scene.

In the left top corner you can see a menu of our Scene and the objects what we will add will appear here.

To add our first object we must to go to the top left corner and press the “Game Object” button, after pressing the button we can se the more options.

And here we must to choose 3D object → The object what we want to add.

Once we chose the object what we need we can start working with it we can move it in 3 directions in our dimension,

and also work with the lightening in the game, and here also one more interesting thing which is the Camera — how our object will look like

In the right bottom corner of the Scene you can see the live view of our object, if you want to see how it will look like in the Game you can go to Game near to Scene button

And after adding object you can run it, to do so you must to press a play button.
