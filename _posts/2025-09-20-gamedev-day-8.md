So today we’re going to learn how to animate material of an object in unity!)

The first of all we need to choose an object with what we will work and will animate as always. And so after we chose the object we need to go to animation window and press record button (small red circle like button), and go to Inspector window and chose the color palette and change the color to more transparent.

After that we need to press recording button again and grab our timeline to next movement and then change color to darker one, grab timeline to final movement and copy first color and paste it with Copy/Paste keyboards (CTRL + C & CTRL + V).

After that we need to change the Rendering mode to Transparent.To do so we need to go to Inspector → Material → Rendering mode → Opaque to Transparent. And after that we can go to Animation window and click play button and as we can see we got a ghost like object.
