**Variables — there is the two types of variables “Public and Private”.**

**Public variables** are the variables which we can be accessed from everywhere of your code, lets say we’re building a racing game and we have a multiple cars, but we want them all to have a same speed in this case we can create a public variable and call it in each class of each car.

```csharp
class racer{
    public int speed = 5;
  
}
```

**Private variables** are the variables which we can use only inside of the classes like if we have a variable of speed of car in our game which’s name is “speed” we can use it only inside of its class and we cant use this variable in other part of our code if we need to set the same speed lets say to another car which is in another class.

```csharp
class racer{
    private int speed = 5;

}
```

**Data type of Variables.**

There is the types of data of variables types like *\[int, float, bool, string and etc.\]* for storing different kind of data.

```csharp
int speed = 5; // for storing a whole numbers and values

float speed = 5.0; // for storing a float numbers and values

bool engine = True; // for storing the condition for examole is the engine of car is on or off

string racer_name = "Jack"; // for storing the names or text
```

So why we need the variables we need them to make our code more easy to change and work with.
