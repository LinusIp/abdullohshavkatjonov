To animate an object in multiple ways or give to the object multiple animations as always we need to go to **Animation** window and choose our object after that we need to click to the name of our object below the **Preview** in **Animation** window and select “**Create New Clip**”.

![Picture from this post](https://cdn-images-1.medium.com/max/800/1*jcFPdke-23WHtDpP1bjMFg.gif)

After that we need to save our new animation in animation folder and after saving we need to switch to our new animation by clicking on it’s name below **Preview**.

And now we can start creating a new animation for our object. To do so again we need to go to **Animation** window and click to record button. and move our object for getting animation after that we need to gram our time line for few seconds and create our nev move and again by grabbing our time line by few seconds we need to copy and paste our first move in order to get a good animation.

![Picture from this post](https://cdn-images-1.medium.com/max/800/1*sp8SIObEDs31YrN4xEa7GA.gif)

So now as you can see we added a new animation to our cube, but here one problem which is if we run our Game we will see only our first animation.

![Picture from this post](https://cdn-images-1.medium.com/max/800/1*bSq6PAmNRj0eS0DGMoQlrQ.gif)

To fix that we nee to go to Animator window and right click to our second animation which’s name is a **cube\_way** and select Set as **Layer Default State.**
