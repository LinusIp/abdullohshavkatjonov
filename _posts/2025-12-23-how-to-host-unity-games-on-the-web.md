I hosted my game on the Web, how?

Well it is simple with WebGL, first I go to File and from here to Building Settings and choose the WebGl if it was not installed, so I downloaded it in Unity Hub.

And now I go to File → Building Settings and chose WebGL, Build and after that I created a new Folder called WebGL so that it wouldn’t messed up with other projects and press select folder after that it will compile and when it finishes compiling you will get an HTML file which you can post on your website or run by clicking it.

But when clicked to run the game I got this error, so I find what the problem is in later Versions of Unity for security reasons they don’t allow to run games locally, but when I chose to ***Buil And Run*** in Building Settings in **WebGl** it worked.
