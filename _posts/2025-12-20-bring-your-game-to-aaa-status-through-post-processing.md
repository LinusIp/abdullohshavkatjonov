This is how Post Processing can change your game and make it look as AAA game.

So how I made it, the answer is simple, first i created an empty object in Hierarchy and call it Post Process Volume, then I added a new Layer in the Inspector with name Post Processing.

![Picture from this post](https://cdn-images-1.medium.com/max/800/1*Xf2M_ozweLwQ8KDKW-UNgA.gif)

And after that we need to adjust this post process to our Main Camera, to do this I go to the Inspector and set Layer to Post Processing, and add a new component which is Pos-Processing Layer and set Layer to Post Processing.

![Picture from this post](https://cdn-images-1.medium.com/max/800/1*XMxBMigTJg5DRwubcz7aBg.gif)

And the I can go to the Inspector window of Post Process Volume and a new effects like Bloom, Color Grading, and more. And work with them and edit add new effects like in photoshop and that helps to make game more visually stunning.
